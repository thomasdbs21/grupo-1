# Evidencias técnicas de NetAudit

Índices académicos de material real, sin duplicar el software ni cambiar su fuente de verdad.

- [Configuraciones](Configuraciones/README.md): archivos sintéticos y evidencia operacional.
- [Pruebas](Pruebas/README.md): registros históricos, contratos y escenarios reproducibles.
- [Automatización](Automatizacion/README.md): recolección, parsing y ejecución del motor.
- [Topología del laboratorio](Topologia/README.md): Windows, VirtualBox y CSR1000v verificados en las capturas aportadas.

Las pruebas sintéticas y las capturas del laboratorio se identifican por separado. No se ejecutaron conexiones SSH, inferencias o nuevas pruebas del software durante esta regularización documental. El material actual puede incorporar Fase 3; los registros conservan sus fechas y cortes propios.
